# HANDOFF — 日報精簡化討論（2026-09-17）

> 這份是「股流對話」中聊到的儀表板議題，移轉過來續辦。主題：北極星每日回報要怎麼做才對、且不燒 AI 成本。

## 需求（使用者原話）
「我北極星儀表，只是要記錄每日各專案的大方向。」

→ 只要**每專案一行的方向 + 進度**，不需要 commit-level 的 tasks/notes/goals 細節。

## 決策
- 日報最小格式：`worklog/YYYY-MM-DD.json` 只寫 `projects: [{ id, name?, description?, stage?, color?, progress?, next? }]`。
- 已確認 `data/updater.js` **支援**只給 projects 的最小格式，不需要 tasks/notes/goals 也能更新儀表板。

## 現況量測（實測）
- 腳本 `data/git-scanner.js` 自動產出：**3,222 bytes**、0 token、但 task 標題是 commit 原文照貼、projects/goals 全空。
- 現行 AI 版 `worklog/2026-09-17.json`：**7,934 bytes**、1 次 AI turn、有品牌描述/決策/目標，但對「只記大方向」而言過重。

## 提案（0 AI 路線，待實作）
1. 使用者每天只維護 `daily-brief.txt`，每專案一行：
   ```
   guru: 88 | P0修復+VIX上線+推GitHub | 驗散戶多空比公式
   ig-car: 15 | 品牌定案，等帳號設定 | 首波9篇 Carousel
   ```
2. 新增 `scripts/daily-report.js`（本機、0 AI）：
   - 讀 `daily-brief.txt` → 產生 `worklog/YYYY-MM-DD.json`（只含 projects）
   - `node data/updater.js` → `npm run build`
   - `git add -A && git commit && git push`
3. 執行方式：雙擊 bat，或 Windows 工作排程每晚自動跑（免費）。
4. 加成：`guru`（股流）那一行可由 `git-scanner.js` 自動從當日 commit 填摘要，使用者只需手動補 IG／YT 等非程式專案。
